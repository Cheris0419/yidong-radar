# 异动雷达 · 前端设计 brief

## 产品

**异动雷达** —— A 股「严重异动监管触发线」测算工具（网页版）。用户是短线交易者，
核心动作：输入股票代码 → 一眼看到未来 10 个交易日「触发严重异动」的价格与涨幅，
判断还有多少空间、哪条规则先触发。参考截图：`docs/reference.jpg`（微信小程序，供信息架构参考，
**视觉不要照抄**，要做出自己的气质）。

页面唯一的主线是：**股票 → 现在的偏离值/次数 → 未来 10 天的触发线表格 → 计算口径**。

## 身份与记忆点

把「雷达 / 盘口监视器」这个隐喻做成页面的签名元素：股票摘要卡里有一枚**雷达扫描环**
（同心圆 + 缓慢旋转的扫描扇区，市场开市时转动、休市时静止；`prefers-reduced-motion` 时不动）。
雷达中心是现价，环形刻度上标出 10 日/30 日触发价的方向感。全站只保留这一个动效亮点，其他克制。

## 视觉基调

深夜盘口仪表：不是纯黑 SaaS 风，而是「深墨蓝绿」的仪器面板。

- 背景（由深到浅）：`#050D14` / `#081420` / `#0D1B29`
- 面板描边：`rgba(148, 210, 226, 0.10)`；分隔线：`rgba(148, 210, 226, 0.08)`
- 主文字：`#E9F1F7`；次文字：`#8FA6B6`；弱文字：`#5F7686`
- A 股语义色：上涨/触发红 `#FF4D4F`，下跌绿 `#2BD9A0`；警示琥珀 `#F5B42E`；安全青绿 `#3DDC97`
- 面板内可加极淡的网格/噪点（CSS gradient，不要贴图）

字体：系统字体栈即可（`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"`），
但**数字必须有仪表感**：`"DIN Alternate", "Bahnschrift", ui-monospace, "SF Mono", Menlo, monospace`，
并开 `font-variant-numeric: tabular-nums`。App 名「异动雷达」可用宋体字重（`"Songti SC", serif`）做对比，
但只出现在顶部 wordmark。

## 布局

移动优先（375–430px 为主场景），桌面（≥1000px）自适应。

```
手机                              桌面
┌────────────────────┐        ┌──────────────┬───────────────┐
│ wordmark   数据时间 │        │ 左栏(sticky) │ 右栏           │
│ [搜索框          ] │        │ 摘要卡+雷达  │ 触发线表格      │
│ [自选 chips]        │        │ 三张详情卡   │ 详情卡(可换位)  │
│ ┌ 摘要卡/雷达 ────┐ │        │              │ 计算口径/风险   │
│ │ 名称 代码 徽标   │ │        └──────────────┴───────────────┘
│ │ 现价 +10.02%    │ │        左右比例约 5:6，整页最大宽 1180px
│ │ 指数行 刷新/自选 │ │
│ └────────────────┘ │
│ 提示：以下触发线…   │
│ ┌ 触发线表格 ─────┐ │
│ │ 交易日 | 触发涨幅 | 触发规则 │
│ │ T+0 …           │ │
│ └────────────────┘ │
│ ┌ 10日 100% 卡片 ─┐ │
│ ┌ 30日 200% 卡片 ─┐ │
│ ┌ 同向异动 x/4 ───┐ │
│ 计算口径 / 风险提示 │
└────────────────────┘
```

- 内容左对齐，表格数字右对齐/居中形成列对齐；手机端表格不横向滚动（三列信息压缩成
  「左：T+ 与日期 / 中：触发涨幅大字 / 右：规则行」）。
- 主内容宽度 720px（手机满宽，pad 16px；桌面右栏可到 640px）。

## 组件要点

1. **Top bar**：左「异动雷达」wordmark + 极简副标「严重异动监管触发线」；右：主题切换（日/夜）与
   数据源状态点（绿点=在线）。
2. **搜索**：大输入框（placeholder「输入代码 / 名称 / 拼音，如 000993」），300ms 防抖下拉建议
   （代码、名称、板块徽标，键盘 ↑↓ Enter Esc 可用）；无输入时展示自选 chips 与示例。
3. **股票摘要卡**：`高危/关注/安全` 徽标 + `深主板/沪主板/创业板/科创板` 描边徽标；名称大字（28–32px）；
   代码次要；现价 + 涨跌幅（红涨绿跌）；指数行「深证综指 2491.40 +0.81%」；
   右侧雷达环（140–170px）；`刷新` 与 `☆ 自选` 按钮。
4. **触发线表格**：标题「严重异动监管触发线」+ 右侧小字「按未来指数收盘不变估算」；
   表头列：交易日 / 触发涨幅 / 触发规则。
   - 行左：`当日 T+0` 或 `T+1`，日期（`2026-09-18`）小字；今日行加「当日」；
   - 行中：触发涨幅大字（红），下挂「触发价 20.71」；若已超线（<0）显示「已超线」态；
   - 行右：规则行 `10 日 100% 触发价 20.71` / `30 日 200% 触发价 28.83` / `十日同向异动线 21.71`；
     绑定规则（binding）用亮白粗体 + 左侧红点/短竖线，其余灰字；非绑定规则可折叠为次要层级。
   - 相邻行用发丝线分隔，不要每行都做成独立卡片。
5. **三张详情卡**：`10日 100% 偏离值` / `30日 200% 偏离值` / `10日同向异动红线`。
   每张：标题 + 徽标；大数字；进度条（危险段用红/琥珀渐变）；「距 +100% 还差 x%」；
   三格数据（股票区间涨幅 / 指数区间涨幅 / 触发异动价格）；窗口日期区间；
   同向卡：`3 / 4` 大字 + 「上涨同向已有 3 次，距离红线还差 1 次」+ 规则说明 + 最近一次异动行。
6. **计算口径**：折叠面板，列出：累计偏离值 = 区间最低收盘价起算的股票区间涨跌幅 − 同期指数区间涨跌幅；
   10 日窗口 11 条有效日 K、30 日窗口 31 条；区间最低收盘价起算；普通异动连续 3 日 ±20%（主板）/
   ±30%（创业板、科创板）；同向红线主板 4 次、双创 3 次；沪市 10 日触发仅清 10 日线、深市两条线均清、
   清零从监管期结束后一交易日起算；本页仅展示上涨方向阈值 +100% / +200%。
7. **风险提示**：底部小字 + 数据来源（东方财富 / 同花顺公开行情），
   「按公开交易规则辅助估算，不构成投资建议，实际以交易所认定及公司公告为准」。

## 状态

- 加载：骨架屏（表格 10 行占位、数字占位），不要全屏 spinner；
- 错误：内联错误卡，「未找到该股票代码，请检查输入」+ 重试按钮；
- 停牌 / 非交易日：顶部状态条说明，表格照常显示（按最新价测算）；
- 收盘后：标题旁小字「已收盘 · 展示下一交易日起触发线」；
- 搜索空态：展示 3 个示例（如 000993 闽东电力 / 600664 哈药股份 / 300750 宁德时代）+ 自选。

## 交互

- URL 同步 `?code=000993`，可刷新/收藏；浏览器前进后退可用。
- 刷新按钮：点击后按钮图标旋转，数据到达后更新；交易时段每 30s 自动刷新（页面不可见时暂停），
  非交易时段不自动刷新。
- 自选：localStorage 保存 `{code,name}` 列表，点击 chip 直接切换；最多 12 个。
- 点击触发价可复制到剪贴板，并有轻量 toast「已复制 20.71」。
- 键盘可访问：焦点环清晰；表格行不是交互元素就不加 hover 位移。

## 技术要求（重要）

- 纯原生 HTML/CSS/JS，**零依赖、零构建、零 CDN**（离线可用）。文件：`web/index.html`、`web/styles.css`、`web/app.js`。
- 只通过 `fetch('/api/triggers?code=')` 与 `fetch('/api/search?q=')` 取数；字段见 `docs/BACKEND-CONTRACT.md`，
  示例响应见 `docs/api-sample-triggers.json`、`docs/api-sample-search.json`。
- 支持 `prefers-color-scheme`（默认深色，顶栏可切日/夜，选择存 localStorage）。
- 响应式 375px → 1440px；字体大小用 `rem`/`clamp()`；尊重 `prefers-reduced-motion`。
- 可本地预览：自己写一个仅用于开发的 `web/dev_server.py`（标准库，端口 8099，提供 `web/` 静态文件、
  `/api/triggers` 返回示例 JSON、`/api/search` 返回示例 JSON），放在 web/ 目录内，不影响生产代码。
- 中文文案自然、克制、准确；不要出现营销式夸张用语。
